# Aurora Nyxus - Voice

Register modelled on Oxide Computer: serious engineers talking plainly to
serious engineers, with quiet confidence and no hype. Layered on Canadian
spelling and no em-dashes.

## Attributes

| Attribute | Do | Don't |
|-----------|-----|-------|
| Terse | Short, declarative. "Compute you own." | Marketing run-ons, adjective stacks |
| Confident | State capability plainly; let specs speak | Overclaim, "revolutionary", superlatives |
| Technical-poetic | Precise nouns with rhythm; "Fig. N" framing | Jargon soup or dumbed-down fluff |
| Honest | Name tradeoffs (break-even, supply reality) | Hide the premium |
| Sovereign | Own, control, custody, verifiable, Canadian | Crypto-hype, buzzword sovereignty |
| Craft-proud | Built, stress-tested, stood behind | Mass-produced, commodity language |

## Signature lines

- "Compute you own."
- "On soil you trust."
- "Spec. Build. Own."
- "You pay a premium once. You stop renting forever."

## Lexicon

**Use:** compute you own, sovereign, on-prem, custody, verifiable, meshed
capacity, node, stress-tested, Canadian, break-even, fixed cost.

**Avoid:** gamer, rig, beast, blazing-fast, revolutionary, game-changer,
unlock, supercharge, crypto/token language, em-dashes.

## Patterns

- Compress the value prop to 3-5 words where possible.
- Let a number carry the claim ("24 GB VRAM. 30B models. Local.").
- State the tradeoff in plain order (cost, then payoff).
- Never write what something is NOT before what it IS. State the positive.

Full brand voice lives in the venture vault; this is the public-facing subset.
