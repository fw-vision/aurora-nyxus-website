# ADR 0004 - Aurora-dark theme (Oxide reference class)

## Status
Accepted

## Context
The brand must read as precision-engineering prestige to labs, funds, and
government, differentiating from Alpha PC's gamer-storefront aesthetic. The
name (Aurora Nyxus: aurora + Nyx, night) suggests a celestial-night palette.

## Decision
Dark-first theme modelled on Oxide Computer: near-black canvas, monospace-forward
technical detail, "Fig. N" engineering framing, dot-grid texture. The signature
accent is the aurora (northern-lights) gradient: green -> cyan -> violet,
rationed to hero moments and key rules.

## Consequences
- No light backgrounds without strong reason; no RGB gamer aesthetic.
- The aurora gradient is the one colour-drama moment; overuse dilutes it.
- Syne (brand/wordmark) + Inter (display; open stand-in for ABC Diatype) + IBM Plex Mono (technical). Numbers act as display elements.
- Colour language: green = owned/workstations, violet = sovereign, cyan = signal.
